## What I’m Building

I’m developing a **15-week portfolio of cloud and AI security projects**, connecting architecture decisions with working implementations and measurable security tests.

The portfolio will cover:

- **Cloud foundations:** Landing zones, infrastructure as code, governance and secure networking.
- **Identity security:** Least privilege, Zero Trust, workload identities and access lifecycle management.
- **Secure delivery:** CI/CD security, policy as code and software supply chain controls.
- **Security operations:** Cloud posture assessments, detection, investigation and recovery.
- **AI and agentic security:** Secure retrieval, tool authorization, prompt injection testing and security evaluations.
- **Cloud FinOps:** Cost visibility, resource ownership and optimization.

Each completed project will include deployment instructions, an architecture diagram, security tests, sanitized evidence, cost considerations and a short demonstration.
